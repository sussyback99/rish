**rish** — лёгкая интерактивная командная оболочка для Unix-систем, написанная на C++20.

Название расшифровывается как **R**untime **I**nteractive **Sh**ell — интерактивная оболочка времени выполнения.

---

## Возможности

- **Модульная архитектура** — вся логика и инклюды вынесены в `assets/headersh.hpp`, а основной файл (`rish.cpp`) остаётся чистым.
- **Уникальный синтаксис флагов** — поддержка `@`-префикса для флагов (например, `@cwd`, `@n`, `@myuid`), отделяющая настройки от обычных аргументов.
- **Динамический промпт** — имя пользователя, хост, текущий путь (с сокращением домашней директории до `~`) и автоматическое определение прав: `$` для обычных пользователей и `#` для суперпользователя (`root`).
- **Цветной вывод** — ANSI-подсветка промпта и подсказок.
- **История команд** — сохраняется между сессиями в `~/.rish_history`.
- **Fish-style подсказки** — при вводе показывается тускло-красный «призрак» похожей команды из истории.
- **Tab-принятие подсказки** — одна клавиша, чтобы дополнить команду.
- **Сырой ввод** — посимвольная обработка без ожидания Enter.
- **Минимальные зависимости** — только стандартная библиотека C++ и POSIX.

## Команды

В `rish` реализован собственный набор встроенных команд с поддержкой кастомных флагов:

### `print`
Печатает текст на экран. Поддерживает флаги в любом порядке и произвольный текст в качестве аргументов.
- **Флаги:**
  - `@cwd` — вывести текущую рабочую директорию.
  - `@n` или `@nonewline` — не добавлять перенос строки в конце.
- **Примеры:**
  - `print Привет, мир!` — стандартный вывод текста с переносом строки.
  - `print @n Текст без переноса` — печать без перевода строки.
  - `print @cwd` — вывод пути текущей директории.

### `who`
Выводит информацию о пользователе.
- **Флаги:**
  - `@myuid` — выводит числовой идентификатор пользователя (`UID` / `EUID`).
- **Пример:**
  - `who @myuid` — покажет `0` под рутом или ID твоего пользователя.

### `cd`
Смена текущей рабочей директории.
- **Примеры:**
  - `cd /etc` — перейти в указанную папку.
  - `cd ~` или просто `cd` — вернуться в домашнюю директорию.

### `exit`
Завершает работу оболочки `rish` и сохраняет историю команд.

## Требования

- Компилятор с поддержкой **C++20** (GCC 10+, Clang 10+)
- **Linux** или другая Unix-подобная система (используются `unistd.h`, `termios.h`)

```bash
g++ -std=c++20 -Wall -Wextra -O2 -s rish.cpp -o rish
```

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Tab | Принять подсказку из истории |
| ↑ | Предыдущая команда из истории |
| Backspace | Удалить символ |
| Enter | Выполнить команду |
